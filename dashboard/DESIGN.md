# Deco Console

Greenfield standalone surface: no existing dashboard UI or component kit was present in deco-cwmp. Reuse the vendored Pico CSS v2 Slate theme for all buttons, inputs, dialogs, tables, typography, focus states and color tokens. Do not implement a second component system. Layout CSS uses Pico variables; no custom shadows, borders or palette.

Persistent navigation, a restrained overview with operational metrics, node cards, searchable client table, and dedicated settings screens. Raw diagnostic data is secondary, in details disclosures. Never imply unavailable data is zero or healthy. Mark fallback, stale and unverified actions explicitly. Wi-Fi secrets are not sent to the browser by default. Destructive changes require an explicit confirmation; opening a screen only reads.
